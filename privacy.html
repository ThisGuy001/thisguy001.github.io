Privacy Policy

Last updated: 2 November 2026

drive2notebook (“the app”) is a personal study tool run by its owner for the owner’s own use. This policy explains how it handles Google user data.

Google user data the app accesses

  • Google Drive files (read-only): the names, folder structure and contents of the files in the Drive folder that the signed-in user chooses.
  • One Google Doc created by the app: the app can create and edit only the Google Doc it creates itself, which lists links to the generated notebooks.
  • Basic account information (the email address of the signed-in account) to show which account is connected.

How the data is used

The files are downloaded temporarily, uploaded to the user’s own NotebookLM account, and used there to create flashcards and quizzes. The app uses Google user data only to provide this feature.

Storage and retention

  • The sign-in credentials are kept as encrypted secrets in the owner’s private GitHub repository settings.
  • A progress file containing file names and identifiers is kept in that private repository so that work can resume.
  • File contents are processed on a temporary computer that is discarded after each run. The app does not keep copies of file contents.

Sharing

The app does not sell Google user data, does not share it with advertisers or data brokers, and does not use it for advertising. The only place file contents are sent is NotebookLM, a Google service, under the signed-in user’s own account.

Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
