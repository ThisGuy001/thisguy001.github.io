drive2notebook

drive2notebook is a small personal study tool. It reads the files in a Google Drive folder that the signed-in user can already open, adds them to NotebookLM notebooks, and asks NotebookLM to create flashcards and quizzes from them. It then writes the links to those notebooks into one Google Doc so they are easy to share.

What it uses from your Google account

  • Read-only access to Google Drive files, to read the files in the folder you choose.
  • Permission to create and edit the single Google Doc that the tool itself makes (the list of notebook links).

It does not edit, move or delete any of your existing files.
